\# YouTube Video Summarizer



An AI-powered YouTube Video Summarizer built using Python, Streamlit, Faster-Whisper, Groq API, yt-dlp, PyVis, and NetworkX.



\## Live Demo



Live demo link will be added after deployment.



\## Features



\- Paste a YouTube video URL

\- Generate instant AI summary

\- Generate complete transcript

\- Create interactive timestamps

\- Generate visual mind map

\- Download summary/mind map as PDF



\## Tech Stack



\- Python

\- Streamlit

\- Faster-Whisper

\- Groq API

\- yt-dlp

\- ffmpeg

\- PyVis

\- NetworkX
